# 编码 Agent 引导手册

给任意编码助手：引导使用者完成同传课堂的安装和使用。不限 Cursor / Claude Code / Copilot / Windsurf / Cline 等。

同学应先把 [AGENT_PROMPT.md](AGENT_PROMPT.md)（与 GitHub 首页同一段）整段发给你。安装细节（venv、`.env`、禁令）以 [USAGE.md](USAGE.md) 为准。**本文只列「有哪些操作」以及你该怎么带着用户做。**

原则：

1. 你跑终端、改仓库、解释按钮；Obsidian 路径、点界面由用户自己做。麦克风：启动后让用户点系统弹窗「允许」，不要先让他去系统设置里找。Key：用户没给就让他自己填；他明确让写入本地 `.env` 时你帮写，不要复述、不要 commit。
2. 不要主动打开、复述、整份覆盖已有 `.env`。不要 `git add .`。不要提交 `data/` 和录音。**不要 `git push` 到这个远程仓库。**
3. 一次只引导一步，等用户说「好了」再下一步。上课中途不要让用户改翻译引擎或切课。

## 操作总表

按使用者生命周期排列。括号里是界面入口。

**A. 装好并能打开（每人一次）**

1. 克隆仓库：`git clone https://github.com/rehtd/course-translate.git`
2. Python 3.11+、建 `.venv`、装 `requirements.txt`
3. `.env` 至少一种翻译 Key（腾讯/百度/阿里/百炼/DeepSeek 均可；笔记才需要 DeepSeek）。用户没给 Key 就让他自己填；他让你写本地 `.env` 就写入。机器翻译教程：[CSDN](https://blog.csdn.net/weixin_44253490/article/details/126365385)
4. 启动应用（`python main.py` 或双击 `启动同传课堂.command`）
5. 系统弹出麦克风授权时点「允许」（不要先去系统设置里找；曾经点过不允许再用应用里的按钮打开设置）
6. 设置：Obsidian 库路径；课堂翻译选已填 Key 的引擎（腾讯云可用）；识别模式用默认即可

**B. 课前准备**

7. 新增 / 重命名 / 删除课程（「＋ 课程」或课程列表右键）
8. 上传或更换「课程总览课件」PDF（课程右键）
9. 手工编辑课程术语表（课程右键 → 术语表）

**C. 上课录制**

10. 先点左侧课程，再「＋ 新建一节课」
11. 看底部英文悬浮字幕；主窗口上英文、下中文（译文可慢几秒）
12. 显示/隐藏字幕（菜单「字幕」）
13. 课间：**暂停**（主窗口或右下角控制条；空格，需先点一下控制条）
14. 打点标记（控制条 ★，或焦点在控制条时按 M）
15. 下课：**结束**（不要在课间结束；控制条 Esc 或主窗口「结束」）
16. 录制中不要切课程、不要切课节、不要改翻译引擎

**D. 课后：回看与录音**

17. 点课节：一句一块上英下中，双击回听
18. 搜索译文/原文
19. 「全文」窗口（双语 / 中文 / English）
20. 「导出」为 Markdown
21. 「继续录制」补录到同一节（课间请用暂停，不要靠这个当休息）
22. 压缩本节录音（结束时弹窗，或课节右键）
23. 重补失败译文（课节右键；没有失败句则是灰的）
24. 重命名课节（课节右键）

**E. 术语、课件、笔记**

25. 从本课提取术语（课节右键；勾选后才写入，改译默认不勾）
26. 上传或移除「本节课件」PDF（课节右键）
27. 「计入笔记」：预览 Markdown → 确认后写入 Obsidian（概念卡清单只能看新建/合并，改定义请到库里改）

**F. 本应用做不到（不要教用户去找）**

- 上课时改某一句译文
- 自动识别中英切换（固定英→中）
- 用现成 wav 当麦克风再跑一遍识别
- Windows 当稳定上课机
- 把别人的 Key 或课堂录音放进 Git

## 分步怎么说（界面）

### A. 安装启动

按 [USAGE.md](USAGE.md) 第 1–5 步。用户没给 Key 时你停住；他让写入 `.env` 时按 USAGE 第 3 步帮写。启动成功：出现「同传课堂」窗口，状态栏类似「就绪 · 选择课程后点击新建一节课」。系统若弹出麦克风授权，让用户点「允许」，不要先让他去设置里翻。

第一次识别会下载 Whisper，可能要几分钟。失败看窗口状态栏或 `data/app.log`（不要把日志里的路径当 Key 发出去）。

常见卡住：

- `python3` 是 3.9：停下来让用户先装 3.11+（python.org 或 Homebrew），不要用系统 Python 建 venv。
- 弹「缺少翻译配置」：回到 USAGE 第 3 步。没给 Key 就等他自己填（占位符不算）；他让写入 `.env` 则帮写。不要主动 `cat .env`，不要把 Key 贴回聊天。
- Finder 双击 `.command` 打不开：让用户右键 → 打开；或改用终端 `source .venv/bin/activate && python main.py`。
- 没声音 / 开录失败：先看有没有系统麦克风弹窗。曾经点过不允许：用应用里的「打开麦克风设置」，打开开关后**完全退出再打开**。
- 切到 PPT 后字幕不见了：确认 `pip install -r requirements.txt` 已装完（含 `pyobjc-framework-Cocoa`）；菜单「字幕」可再显示。

### A6. 设置

点右上「⚙ 设置」：

- **Obsidian vault**：浏览到用户的库根目录。不选则「计入笔记」写不进去。
- 笔记子目录默认 `01-章节笔记`，概念卡默认 `02-概念卡片`，一般不用改。
- **翻译引擎**：任选已填 Key 的即可上课，不必 DeepSeek。对比见 [USAGE.md「翻译引擎怎么选」](USAGE.md#翻译引擎怎么选)。
  - DeepSeek / 百炼 / Ollama：吃术语表和上下文。
  - 腾讯 / 百度 / 阿里机器翻译：快、有免费额度，但不吃术语表，课名容易乱。
  - 笔记整理、提取术语始终走 DeepSeek，和这里无关。
- 识别模式：默认「实时」。只有框内英文总被环境音带跑时再试「精准」（字幕仍然短窗，不会明显变慢）。

录制中翻译引擎是锁住的，下课再改，下一场才生效。

### B7. 课程

「＋ 课程」或课程列表空白处右键「新增课程」。填代码（如 IS6335）和名称。右键可重命名、删除（删课程会连课节，先确认）。

### B8 / E26. 课件 PDF

- 整门课：课程右键 → 上传/更换课程总览课件（PDF）
- 这一节：课节右键 → 上传本节课件

必须是能选中文字的 PDF。扫描件抽不出字；PPT 请用户先另存 PDF。计入笔记时会抽字。

### B9 / E25. 术语表

课上翻译吃的是课程术语表，不是概念卡片。

- 手改：课程右键 → 术语表。每行 `English = 中文`。
- 课后抽：课节右键 → 从本课提取术语。弹出后：**新建默认勾，改译默认不勾**。用户勾完再写入。已在表里的会跳过。

告诉用户：写进去后 **下一节课** 才明显帮翻译；刚写完的这一节已经译完了。

### C. 上课

1. 左侧点课程（不要在录制中再点别的课）。
2. 「＋ 新建一节课」。主区变成上英文、下中文两个大框；底部出现英文字幕；右下角控制条。
3. 用户对着老师/扬声器，看英文是否在跟。中文框可以晚几秒。
4. 课间只点「暂停」。暂停时仍在写 wav（磁盘会涨）。
5. 下课点「结束」。约 4 分钟以上的录音会问是否压成 m4a；可以「以后」，再在课节右键压缩。

麦克风失败：用应用弹窗里的「打开麦克风设置」，打开开关后**完全退出应用再开**，不要只关窗口。不要让用户自己在系统设置里翻。

### D. 回看

点已结束的课节。主区改成一句一块上英下中。双击该句回听。没有录音文件时会提示无法回听。

「继续录制」会另存一段 wav，结束后仍算同一节。课间休息不要用这个。

### E27. 计入笔记

先确认设置里有 vault。点「计入笔记」：选目标课程、短标题 → 等生成 → 预览里可改课节 Markdown → 确认写入。

概念卡区域只显示新建/合并，不能在弹窗里改卡片正文。要改定义去 Obsidian 的 `02-概念卡片`。笔记整理始终走 DeepSeek，和设置里的「翻译引擎」无关。

## 你不要主动做的

- 做成 dmg/exe 给人下载
- `git push` 到 origin
- 把录音或 `data/` 推进 Git
- 为 Windows 重写识别翻译
- 语种自动切换、课上改译文、用文件当麦克风
