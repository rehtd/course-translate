# 编码 Agent 引导手册

装好并能打开窗口之后，带着使用者点界面。安装、Key、启动以 [USAGE.md](USAGE.md) 为准。提示词与 GitHub 首页同一段，见 [AGENT_PROMPT.md](AGENT_PROMPT.md)。

原则：一次只引导一步，等用户说「好了」再下一步。你跑终端、解释按钮；点界面、选 Obsidian 路径由用户自己做。上课中途不要让用户改翻译引擎或切课。

打不开、缺 Key、Python 太旧：回到 [USAGE.md](USAGE.md)，不要在本文重做安装。

## 操作总表

**A. 设置（窗口已经打开）**

1. 右上「⚙ 设置」：Obsidian 库路径；课堂翻译选已填 Key 的引擎；识别模式用默认即可

**B. 课前准备**

2. 新增 / 重命名 / 删除课程（「＋ 课程」或课程列表右键）
3. 上传或更换「课程总览课件」PDF（课程右键）
4. 手工编辑课程术语表（课程右键 → 术语表）

**C. 上课录制**

5. 先点左侧课程，再「＋ 新建一节课」
6. 看底部英文悬浮字幕；主窗口上英文、下中文（译文可慢几秒）
7. 显示/隐藏字幕（菜单「字幕」）
8. 课间：**暂停**（主窗口或右下角控制条；空格，需先点一下控制条）
9. 打点标记（控制条 ★，或焦点在控制条时按 M）
10. 下课：**结束**（不要在课间结束；控制条 Esc 或主窗口「结束」）
11. 录制中不要切课程、不要切课节、不要改翻译引擎

**D. 课后：回看与录音**

12. 点课节：一句一块上英下中，双击回听
13. 搜索译文/原文
14. 「全文」窗口（双语 / 中文 / English）
15. 「导出」为 Markdown
16. 「继续录制」补录到同一节（课间请用暂停，不要靠这个当休息）
17. 压缩本节录音（结束时弹窗，或课节右键）
18. 重补失败译文（课节右键；没有失败句则是灰的）
19. 重命名课节（课节右键）

**E. 术语、课件、笔记**

20. 从本课提取术语（课节右键；勾选后才写入，改译默认不勾）
21. 上传或移除「本节课件」PDF（课节右键）
22. 「计入笔记」：预览 Markdown → 确认后写入 Obsidian（概念卡清单只能看新建/合并，改定义请到库里改）

**F. 本应用做不到（不要教用户去找）**

- 上课时改某一句译文
- 自动识别中英切换（固定英→中）
- 用现成 wav 当麦克风再跑一遍识别
- Windows 当稳定上课机
- 把别人的 Key 或课堂录音放进 Git

## 分步怎么说（界面）

### A1. 设置

点右上「⚙ 设置」：

- **Obsidian vault**：浏览到用户的库根目录。不选则「计入笔记」写不进去。
- 笔记子目录默认 `01-章节笔记`，概念卡默认 `02-概念卡片`，一般不用改。
- **翻译引擎**：任选已填 Key 的即可上课，不必 DeepSeek。对比见 [USAGE.md「翻译引擎怎么选」](USAGE.md#6-翻译引擎怎么选)。
  - DeepSeek / 百炼 / Ollama：吃术语表和上下文。
  - 腾讯 / 百度 / 阿里机器翻译：快、有免费额度，但不吃术语表，课名容易乱。
  - 笔记整理、提取术语始终走 DeepSeek，和这里无关。
- 识别模式：默认「实时」。只有框内英文总被环境音带跑时再试「精准」（字幕仍然短窗，不会明显变慢）。

录制中翻译引擎是锁住的，下课再改，下一场才生效。

切到 PPT 后字幕不见了：确认已按 USAGE 装完依赖（含 `pyobjc-framework-Cocoa`）；菜单「字幕」可再显示。

### B2. 课程

「＋ 课程」或课程列表空白处右键「新增课程」。填代码（如 IS6335）和名称。右键可重命名、删除（删课程会连课节，先确认）。

### B3 / E21. 课件 PDF

- 整门课：课程右键 → 上传/更换课程总览课件（PDF）
- 这一节：课节右键 → 上传本节课件

必须是能选中文字的 PDF。扫描件抽不出字；PPT 请用户先另存 PDF。计入笔记时会抽字。

### B4 / E20. 术语表

课上翻译吃的是课程术语表，不是概念卡片。

- 手改：课程右键 → 术语表。每行 `English = 中文`。
- 课后抽：课节右键 → 从本课提取术语。弹出后：**新建默认勾，改译默认不勾**。用户勾完再写入。已在表里的会跳过。

写进去后 **下一节课** 才明显帮翻译；刚写完的这一节已经译完了。

### C. 上课

1. 左侧点课程（不要在录制中再点别的课）。
2. 「＋ 新建一节课」。主区变成上英文、下中文两个大框；底部出现英文字幕；右下角控制条。
3. 用户对着老师/扬声器，看英文是否在跟。中文框可以晚几秒。
4. 课间只点「暂停」。暂停时仍在写 wav（磁盘会涨）。
5. 下课点「结束」。约 4 分钟以上的录音会问是否压成 m4a；可以「以后」，再在课节右键压缩。

麦克风失败：用应用弹窗里的「打开麦克风设置」，打开开关后**完全退出应用再开**，不要只关窗口。不要让用户自己在系统设置里翻。

### D. 回看

点已结束的课节。主区改成一句一块上英下中。双击该句回听。没有录音文件时会提示无法回听。

「继续录制」会另存一段 wav，结束后仍算同一节。课间休息不要用这个。

### E22. 计入笔记

先确认设置里有 vault。点「计入笔记」：选目标课程、短标题 → 等生成 → 预览里可改课节 Markdown → 确认写入。

概念卡区域只显示新建/合并，不能在弹窗里改卡片正文。要改定义去 Obsidian 的 `02-概念卡片`。笔记整理始终走 DeepSeek，和设置里的「翻译引擎」无关。
